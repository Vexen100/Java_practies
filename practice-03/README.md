# Практика №3 — Массивы

- `Task1.java` — вывод элементов массива по два с начала и конца.
- `Task2.java` — количество различных элементов массива.
- `Task3.java` — формирование массива B отдельным статическим методом.
- `Task4.java` — обход квадратной матрицы «уголками».
- `Task5.java` — программа с меню из практики №2 с передачей данных через массив.

В заданиях 1–3 допускается пустой массив. Размер матрицы в задании 4 должен быть положительным.
